# ZERO BOT 機能紹介

ZERO BOT（zero-bot-next）でできることを、1ページにまとめた紹介です。

- **共通機能**：ギルドごとの設定（DynamoDB の `zero_bot_guild_config`）があるサーバーで動きます。設定が無い機能は、そのサーバーでは何もしません。
- **rainbowl 専用機能**：`rainbowl` 設定を持つサーバーでだけ動きます。

> コマンド名の横の 🔒 は **管理者専用** です（Discord の管理者権限が必要）。

## 1. VC まわり

### VC 入退室の通知 & インチャ転記
VC に人が出入りすると、その VC 専用のテキストチャンネルに自動で通知します。

- 入室・退室を、緑・赤の Embed で投稿します。
- VC のインチャに書かれたメッセージ（画像も含む）を、専用テキストチャンネルへ転記します。
- **プロフィール紹介**：入室した人の最新のプロフィール投稿へのリンクを、ひとことメッセージ付きで投稿します（男女ロールで色分け）。この投稿は、その人が退室すると消えます。
- VC が 0 人になると、そのインチャのメッセージをまとめて削除します（除外カテゴリーは対象外）。

### おやんも（VC 強制移動）😴
寝落ちした人などを、指定の VC へまとめて移動させる機能です。

- 常設の「おやんも」ボタンを押して、VC に接続中のユーザーを選ぶと、移動先 VC へ飛ばします。
- 「〇〇が〇〇を飛ばしました」というログを、設定チャンネルに残します。
- ボタンは使うたびに再投稿され、常に一番下に来ます。
- 🔒 `/set_oyanmo`：常設ボタンを設置します。

### VC ステータス変更（「こいよ」）
VC のインチャで **「こいよ」** とだけ書き込むと、操作パネルが出ます。

- ✏️ **ステータス変更**：VC のステータスを設定します（80 文字まで）。
- 🧹 **ステータス解除**
- 😴 **おやんも**：パネルからもおやんもできます。
- 操作できるのは呼び出した本人だけです。パネルは 3 分で期限切れになります。

## 2. レベル・ランキング

### XP の付与
VC とテキストの活動で XP がたまります。

| 種類 | 計算 |
|---|---|
| ボイス XP | 1 分ごとに `0.3 × 人数ボーナス × ミュート倍率`<br>人数ボーナス：1 人 0.8／2〜3 人 1.2／4〜6 人 1.5／7 人以上 2.0<br>ミュート中は 0.5 倍 |
| テキスト XP | 1〜79 文字：1／80〜159 文字：2／160 文字以上：3<br>同じ人は 10 秒に 1 回まで |

- VC の滞在時間は日ごとに記録されています（人数帯別・時間帯別・一緒にいた人などの統計）。
- rainbowl は専用の XP テーブルで別に集計しています（二重にはカウントされません）。

### RANK CARD 🪪
常設の「レベル確認」ボタンを押すと、自分のレベルを画像（RANK CARD）で表示します。

- 背景はサーバーごとに変更できます（S3 またはローカル画像）。
- 🔒 `/set_rankcard`：常設ボタンを設置します。

### 管理者向け：`/zbadmin` 🔒
| コマンド | 内容 |
|---|---|
| `/zbadmin show_xp` | 指定ユーザーの XP を表示 |
| `/zbadmin rank` | 指定ユーザーの RANK CARD を表示 |
| `/zbadmin voice_stats` | 指定ユーザーのボイス統計（総滞在時間、人数帯別、ミュート時間、時間帯別、一緒にいた人 など） |
| `/zbadmin voicerank` | ボイス XP ランキング（ページ送りあり） |
| `/zbadmin textrank` | テキスト XP ランキング（ページ送りあり） |
| `/zbadmin voicerank_period` | 期間を指定したボイス通話時間ランキング |
| `/zbadmin voice_time_period` | 指定ユーザーの、期間を指定したボイス滞在時間 |
| `/zbadmin setxp` | XP を加算 |
| `/zbadmin setlv` | 指定レベルになるよう XP を調整 |

## 3. サーバーログ

運営向けのログを、種類ごとに指定チャンネルへ投稿します。Bot の操作は記録しません（人間の操作のみ）。

| ログ | 記録する内容 |
|---|---|
| 管理ログ | ロールの付与（✅）・剥奪（⛔） |
| 編集ログ | メッセージの編集（変更前・変更後、元メッセージへのリンク付き） |
| 削除ログ | メッセージの削除（削除された本文） |
| VC ログ | VC への参加・退出 |
| 退出ログ | サーバーからの脱退（自主退出・Kick・Ban をまとめて記録） |

- テキストチャンネル・VC のインチャ・スレッドが対象です。
- Bot の再起動前に書かれた古いメッセージも追えますが、編集前・削除前の本文は Discord が教えてくれないため「不明」と表示されます。
- 🔒 `/set_server_log_channel`：ログの種類ごとに投稿先を設定します。設定しなかった種類は投稿されません。

## 4. チャンネル便利機能

### 吊り下げ（チャンネル下部に常に表示）
指定したメッセージ（画像も可）を、チャンネルの一番下に常に表示します。

- 誰かが書き込むと、**最後の書き込みから 5 秒後** に古い吊り下げを消して再投稿します。
- テキストチャンネルと VC のインチャで使えます。
- 🔒 `/tsuri_set`：このチャンネルに設定（画像は任意）
- 🔒 `/tsuri_edit`：内容を編集
- 🔒 `/tsuri_off`：解除

### カラーコードのプレビュー 🎨
VC のインチャに `#FF8800` のようなカラーコード **だけ** を書き込むと、その色の見本画像を返します。

### アーカイブの整理
- 🔒 `/manage_comment date:yyyymmdd`：アーカイブカテゴリー内の、指定日以前のチャンネル（`yyyymmdd_` で始まるもの）をまとめて削除します。

## 5. BDSM 相性チェック

男性用・女性用の「BDSM 結果 URL チャンネル」に、bdsmtest.org の結果 URL を貼っておくと、ほかの登録者との相性を確認できます。

- `/bdsm_check`：このチャンネルに登録されているユーザーとの相性 % を、ランキングで表示します（結果は本人にだけ見えます）。
- 実行した記録は、運営用のログチャンネルに残ります。
- 設定が無いサーバー、または無効にしているサーバーでは使えません。

## 6. rainbowl：入場〜面談〜合格

入場から正式メンバーになるまでを、Bot が段階的に案内します。

```
入場 → 案内を1ページずつ読む → 入会申請 → プロフィール提出
     → 運営が受付 → 面談 → /ok or /ng → 了解しました → プロフィール投稿 → 新人
```

| 段階 | Bot がやること |
|---|---|
| **入場** | 「入場者」ロールを付与し、運営に入場者情報（入場回数・前回の審査状況）を通知 |
| **案内を読む** | 各チャンネルの「次へ」ボタンで、次の案内をその人にだけ開放 |
| **入会申請** | 「申請中」ロールに変更し、本人＋運営だけが見える専用チャンネルを作成。案内文とプロフィールのテンプレートを投稿 |
| **受付** | 運営がプロフィール投稿に「受付」スタンプを押すと、プロフィールを確定し「応募者プロフ置き場」へ転記 |
| **合否** | 運営が専用チャンネルで `/ok`（コメント任意）または `/ng`（理由必須）を実行 |
| ├ 合格 | 「合格」ロールにして規約カテゴリーを開放。合否記録を緑で保存し、本人に「了解しました」ボタンを送信 |
| └ 不合格 | 本人への通知なしで自動キック。合否記録を赤で保存 |
| **了解しました** | 「了承済み」ロールに変更 |
| **プロフィール投稿** | 男性・女性プロフィールチャンネルへの最初の投稿を検知して「新人」ロールに変更し、専用チャンネルを削除 |

- 再入場した人は、前回の挑戦が履歴として残ります。
- 🔒 `/ok`・`/ng`：合否処理（運営専用）
- 🔒 `/rainbowl_setup_buttons`：「次へ」「入会申請」ボタンを設置（手動セットアップ用）

詳しい仕様：[rainbowl/bot設計_入場から面談合否までのフロー.md](rainbowl/bot設計_入場から面談合否までのフロー.md)

## 7. rainbowl：ロール付与ボタン

メンバーが自分でロールを付け外しできるボタンです。押すと付き、もう一度押すと外れます。

- **必須ロール**：性別（男性／女性）、パートナーの有無
- **任意ロール**：募集用ロール（男性募集／女性募集）、深夜募集 など
- ボタンの種類や文言は `data/rainbowl/role_buttons.json` で管理しているため、コードを触らずに変更できます。
- 🔒 `/set_role_button`：ボタンを設置し直します（対象チャンネルにある Bot のメッセージは削除されます）。

## 8. rainbowl：プライベートルーム

メンバーが自分で一時的な VC を作れる機能です。

### 部屋の種類
| 種類 | 見える人 | 入れる人 |
|---|---|---|
| プライベート会議 | 作成者＋招待した人 | 作成者＋招待した人 |
| プライベート個室 | 同上（1 対 1 用） | 同上 |
| パブリック会議 | 全員 | 全員 |
| パブリック個室 | 全員（1 対 1 用） | 全員 |

### 使い方
- 作成メニューのボタンから、部屋名・人数（3〜99 人、空欄で無制限）を入力して作成します。
- 部屋の VC インチャに出る **ルームメニュー** で、次の操作ができます。
  - 部屋名・ステータス・人数・ビットレートの変更
  - ユーザーの招待／招待解除／招待済みユーザーの確認（プライベートのみ）
- 招待すると人数上限が自動で広がり、解除すると自動で縮みます。
- 作成者として持てる部屋は **1 人 1 部屋まで** です（招待される分には制限なし）。
- **人が 0 人の状態が 1 分続くと、自動で削除されます**（作成直後も同じ）。「自分のルームを削除」ボタンで手動でも消せます。

### 管理者コマンド 🔒
| コマンド | 内容 |
|---|---|
| `/create_vc_menu` | 作成メニューを設置 |
| `/list_vc_menus` | 設置済みメニューの一覧 |
| `/delete_vc_menu` | メニューを削除（既存の部屋は残る） |
| `/restore_vc_room_menu` | VC インチャのルームメニューを再投稿 |
| `/set_vc_log_channel` | 操作ログの投稿先を設定 |
| `/vc_system_off` | 機能を緊急停止 |
| `/vc_system_on` | 機能を再開 |
| `/vc_system_status` | 稼働状態を確認 |

詳しい仕様：[rainbowl/プライベートルーム機能.md](rainbowl/プライベートルーム機能.md)
