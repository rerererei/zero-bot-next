# ロール・チャンネルID一覧

> 目的：`bot設計_入場から面談合否までのフロー.md` を動かすために、実際にDiscord上で作成が必要なロール・カテゴリー・チャンネルを整理し、作成後にIDを控えるための一覧。
> スコープ：入場〜面談合否判定までの範囲に絞る。規約同意後（正式メンバー向けのテキスト交流・VCラウンジ・マッチング機能など）は対象外。合否フローが動くようになった段階で別途一覧化する。
> 作成順序：① ロール ②カテゴリー ③カテゴリー内チャンネル、の順で作るとID参照の手戻りが少ない（チャンネルの権限設定にロールIDが必要なため）。
