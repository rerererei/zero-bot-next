# お問い合わせ窓口

メンバーが運営へ質問・相談・報告するための窓口（2026-10-24実装）。

## 流れ

1. お問い合わせチャンネル（`1563388573917642862`）に、Botが「📮 問い合わせる」ボタン付きのメッセージを設置する（管理者が`/set_inquiry_button`を実行）
2. メンバーがボタンを押すと、モーダルで **件名**（50文字まで）・**内容**（1500文字まで）を入力する
3. 送信すると、お問い合わせチャンネルに **プライベートスレッド**（`{表示名}さん｜{件名}`）が作られる
   - 本人をスレッドに追加し、通知ロール（管理者 `1533518611493290096`・Supporter `1546550998904869088`）をメンションして、件名・内容をEmbedで投稿する
   - 本人には、作成したスレッドへのリンクを本人だけに見える形で返す
4. 以降のやり取りはそのスレッドで行う

## 見える人

- プライベートスレッドなので、見えるのは **本人と、スレッドの管理権限を持つ人** だけ。管理者・Supporterはどちらも Administrator 権限を持つため、すべての問い合わせスレッドを閲覧できる。
- 本人が他のメンバーをスレッドに招待することはできない（`invitable=False`）。
- スレッドは7日間書き込みがないと自動でアーカイブされる（書き込めば再開する）。

## 連打対策

同じ人が30秒以内に続けて送信した場合は受け付けない（二重にスレッドができるのを防ぐ）。

## 設定

`zero_bot_guild_config`の`inquiry`名前空間（任意。無いギルドでは動作しない）。投入スクリプト：[scripts/rainbowl/setup_inquiry_config.py](../../scripts/rainbowl/setup_inquiry_config.py)

```json
"inquiry": {
  "channel_id": "1563388573917642862",
  "notify_role_ids": ["1533518611493290096", "1546550998904869088"]
}
```

文言は[services/rainbowl_texts.py](../../services/rainbowl_texts.py)の`INQUIRY_*`。実装は[cogs/rainbowl_inquiry.py](../../cogs/rainbowl_inquiry.py)。

## Discord側で必要な権限設定

お問い合わせチャンネルの権限（男性・女性ロールなど、メンバーが持つロールに対して）：

- **メッセージを送信**：オフ（チャンネル本体には書き込めないようにする）
- **スレッドでメッセージを送信**：オン（自分の問い合わせスレッドで返信できるようにする）
- **公開スレッドの作成／プライベートスレッドの作成**：オフ（スレッドはBotだけが作る）

BotはAdministrator権限を持っているため、Bot側の追加設定は不要。
