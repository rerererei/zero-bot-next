# 💞 この場所で生まれる関係

rainbowlは恋愛サーバーですが、恋人や固定になることだけをゴールにはしていません。

会話を重ねた先に、こんな関係が生まれます。

- ☕ 気軽に話せる友人
- 🎨 趣味を共有する相手
- 🌙 悩みを話せる相手、日常を共有する相手
- 💭 深く話せる相手
- ✨ オンライン上で特別に感じられる相手
- 💘 恋愛を視野に入れた相手、恋人・固定・相方

関係の名前や形は、周りが決めるものではなく、本人同士が納得して決めるものです。

**既婚者の参加について**

既婚者の参加も認めています。ただしこれは、不倫や配偶者への裏切りを推奨する場所ではありません。

- 婚姻状況・交際状況は正しく申告してください
- 求める関係や交流の範囲を、相手に誤解なく伝えてください
- 関係を深める前に、お互いの希望や境界線を確認してください
- 断られたあとの執拗な接触は禁止です

相性診断の結果や周囲の期待を理由に、特定の関係を相手へ求めることはできません。
