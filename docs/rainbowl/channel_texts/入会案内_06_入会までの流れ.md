# 🗺️ 入会までの流れ

申請から交流開始まで、だいたいこんな流れです。

1️⃣ 入会案内を読む
2️⃣ 面接用プロフィールを作成
3️⃣ 入会申請を送る
4️⃣ 運営が内容を確認・面談日程を調整
5️⃣ 面談
6️⃣ 合否のご連絡
7️⃣ 規約の確認と同意
8️⃣ 本プロフィール作成
9️⃣ 相性診断（心理テスト）に回答
🔟 回答後、交流スタート 🎉

面談前の段階では、正式な規約カテゴリーはまだ見えません。面談に合格すると規約カテゴリーが開放され、同意後は本プロフィール作成・心理テスト回答を経て、交流チャンネルが開放されます。心理テストの回答は入場条件のひとつで、未回答の間は一般メンバー向けチャンネルへ入場できません。

なお、2️⃣の面接用プロフィールは面談のためだけの簡易プロフィールで、8️⃣で作成する他メンバーへ公開される本プロフィールとは別のものです。
