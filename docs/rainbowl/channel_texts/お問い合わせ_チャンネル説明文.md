# 📮 お問い合わせ
運営への質問・相談・報告は、このチャンネルから受け付けています。
気になることがあれば、どんな小さなことでも気軽に送ってください。

## こんなときに使ってください
- サーバーの使い方やルールについての質問
- ロールが付かない・チャンネルが見えないなどの不具合
- メンバーとのトラブルや、困っていることの相談
- 規約違反の報告
- しばらく参加できなくなる、などの連絡
- その他、運営に伝えたいこと

## 使い方
1. 下の **「📮 問い合わせる」** ボタンを押す
2. **件名** と **内容** を入力して送信
3. あなたと運営だけが見られる **専用スレッド** が作られます
4. 運営からの返信は、そのスレッドに届きます。続きのやり取りもスレッドで行います

## ご注意
- 専用スレッドは **あなたと運営（管理者・Supporter）だけ** が見られます。他のメンバーには見えません
- 返信は運営が確認しだい行います。少しお時間をいただく場合があります
- 1つの用件につき送信は1回でお願いします。追加で伝えたいことは、同じスレッドに書き込んでください
- トラブルや違反の報告は、わかる範囲で **いつ・誰と・何があったか** を書いてもらえると対応がスムーズです
- このチャンネルには直接書き込めません。必ずボタンから送信してください
