# 利用ルール

サーバー規約に書かれている内容を、実際の行動レベルで整理したチェックリストです。「これをやったらルール違反になる」という基準として使ってください。条文の根拠や背景はサーバー規約に記載しています。内容に食い違いがある場合は、サーバー規約の内容が優先されます。

**プロフィール・申告について（サーバー規約 3・4章）**

以下はNGです。

- 年齢、性別、婚姻状況、交際状況を偽って申告する
- 現実で会う意思がないのに、あるかのように振る舞う
- オンライン限定を希望しているのに伝えない
- 求めている関係の種類を偽る
- 他人の写真を自分の写真として使う
- 婚姻状況や立場を相手に隠したまま関わる
- 現実で交際できるかのような誤解を意図的に与える

**普段の交流について（サーバー規約 5章）**

以下はNGです。

- 相手を見下す、侮辱する、人格を否定する
- 容姿、声、年齢、経験などを執拗に評価する
- 本人が嫌がっている話題を繰り返す
- 特定のメンバーを仲間外れにする
- 集団で一人を責める、晒す、嘲笑する
- 相手の発言をわざと曲解してトラブルを起こす
- 拒否されたあとも繰り返しDMや通話へ誘う
- 返信や通話参加を強要する

**DM・フレンド申請・個別のやり取りについて（サーバー規約 6・7章）**

以下はNGです。

- 面識のない相手への無差別なDM
- 返信がない相手への連投
- 断られたあとの再勧誘
- 別アカウントを使って接触する
- サーバー外のツール（LINE、X、電話番号など)へ移動するよう強く求める
- 個人情報、写真、連絡先をしつこく要求する
- 「前に同意したから」を理由に、今の相手の気持ちを無視する

**恋愛・性的な話題について（サーバー規約 7・8章）**

以下はNGです。

- 同意のない性的な発言や画像の送付
- 性的な質問への回答を強要する
- 嫌がっている相手へ性的な話題を続ける
- 性的な関係や行為を交換条件にする
- 拒否した相手を責める、晒す、からかう
- 性的な相手を探すことだけを目的として利用する
- 相手の反応が曖昧なまま、同意しているものとして扱う

**個人情報・プライバシーについて（サーバー規約 9章）**

以下はNGです。

- メッセージやプロフィールを無断で転載する
- 通話を無断で録音・録画・配信する
- スクリーンショットを外部へ共有する
- 本名、住所、勤務先、家族構成などを特定・公開する
- 他のサーバーやSNSでメンバーの話題を晒す
- サーバー内のトラブルを娯楽として外部へ持ち出す

運営へ相談するために証拠として提出する場合は例外です。

**Bot・相性診断について（サーバー規約 10章）**

以下はNGです。

- 診断結果を理由に交流を強要する
- 結果が低いことを理由に相手を否定する
- 診断内容を本人の許可なく公開する
- 結果を利用して相手をからかう、格付けする
- Botの不具合や仕様を悪用する
- 他人になりすまして回答する

**その他の禁止行為（サーバー規約 12章）**

以下はNGです。

- 法令、Discordの利用規約・ガイドラインに反する行為
- 荒らし、スパム、過度なメンション
- 差別的、攻撃的、脅迫的な発言
- ストーカー行為や監視行為
- なりすまし、複数アカウントを使った処分逃れ
- 宗教、政治団体、マルチ商法などへの勧誘
- 商品の販売、金銭の貸し借り、投資や副業への勧誘
- 他サーバーへの無断勧誘や引き抜き
- ウイルス、不正ツール、危険なリンクの共有
- 運営または他のメンバーへの虚偽の申告、証拠の捏造

**退会後も適用される行為（サーバー規約 15章）**

サーバーを退会したあとも、以下はNGです。

- サーバーで知り合った相手への執拗な接触
- 別アカウントでの再接触
- サーバー内の情報や会話の転載
- メンバーや運営への晒し、嫌がらせ
- 虚偽の情報を広める行為

**活動量・在籍について（サーバー規約 11章）**

- 長期間交流がなく、関わる意思が確認できない場合は在籍確認や退会の対象になります
- 一時的に活動が難しい場合は、休止制度やステータスを利用してください

**違反した場合（サーバー規約 13・14章）**

違反内容に応じて、注意、機能・チャンネル利用制限、接触制限、一時的な利用停止、強制退会などの対応を行います。重大な行為については、事前の注意なく強制退会とする場合があります。
