# 💛 大切にしていること

このサーバーで一番大切にしているのは、見た目・声・年齢・プロフィールといった一部分だけで相手を決めつけないことです。

- 🗣️ 言葉を交わしながら、考え方や人柄を知っていく
- 🎧 VC派もテキスト派も、どちらも同じように尊重される
- 🌱 会話が得意じゃなくても、自分にできる方法で関わればいい
- 🤍 自分の好意と同じくらい、相手の意思も大切にする

私たちが大事にしたいのは、この一言に尽きます。

> 会話を重ねて、人を知る。人を知って、特別になる。
