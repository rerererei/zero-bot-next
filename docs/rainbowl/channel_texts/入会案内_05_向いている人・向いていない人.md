# 🧭 向いている人・向いていない人

入会後の「思っていたのと違う」を減らすために、正直にお伝えします。

**こんな人に向いています**
- 💬 会話を通して相手を知りたい人
- 🌱 自分のことも少しずつ伝えられる人
- 🧩 友達、特別な話し相手、恋愛など、さまざまな関係を探したい人
- 🤝 相手の価値観や希望する関係を尊重できる人
- ⌨️ テキスト、VCなど、自分に合った方法で交流したい人
- 👣 会話が得意でなくても、自分なりの一歩を踏み出せる人
- 🎲 Bot機能やイベントを交流のきっかけとして楽しめる人

**こんな人には向いていません**
- ROM専として在籍したい人
- 受け身のまま、すべて相手からの接触を待つ人
- 外見・声・年齢・プロフィールだけで相手を評価する人
- 性的な関係だけを目的とする人
- 婚姻状況や交際状況を隠したい人
- 断られたあとも接触を続ける人
- 返信速度や通話頻度、関係の進展を相手へ強要する人
- サーバー内でほとんど活動する意思がない人

会話が得意である必要はありません。大人数のVCに積極的に参加する必要もありません。
ただし、関係を作るための行動をすべて相手任せにする参加は、このサーバーの趣旨と合いません。
