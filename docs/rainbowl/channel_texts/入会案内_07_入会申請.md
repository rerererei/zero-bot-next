# 📮 入会申請

申請の前に、以下を確認してください。

☑️ 入会案内を読んだ
☑️ 年齢・婚姻状況・交際状況を正しく申告できる
☑️ 希望する関係や交流スタンスを正直に伝えられる
☑️ 相手の意思と境界線を尊重できる
☑️ 入会後、自分なりに交流へ参加する意思がある

下のボタンを押すと、あなた専用のチャンネルが作成されます。そのチャンネルにその後の流れとプロフィールのテンプレートを投稿するので、テンプレートをコピーして、同じチャンネルに必要事項を記入してください。内容はあとから編集できます。このプロフィールは運営の面談確認だけに使用し、他メンバーには公開されません。合格後には、他メンバーへ公開する本プロフィールをあらためて作成していただきます。

準備ができたら、下のボタンから申請してください。

**[ 入会を申請する ]**
